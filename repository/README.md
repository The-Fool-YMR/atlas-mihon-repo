# Mihon catalog publisher

This folder contains the Keiyoushi protobuf schema and bindings and a generator for a GitHub-hosted Mihon extension catalog. The generated catalog includes APK and icon downloads, the real Android version code, the actual signing certificate fingerprint, and the source IDs emitted by the extension build.

`index.proto` and `index_pb2.py` come from Keiyoushi extensions-source commit `4591fbc9bb571ad03aaea0f7428f7f403350e90e` and retain its Apache-2.0 license.
