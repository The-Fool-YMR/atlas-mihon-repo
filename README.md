# Atlas Comics — Mihon extension store

Add this URL in Mihon’s extension stores/repositories:

https://github.com/The-Fool-YMR/atlas-mihon-repo/raw/repo/index.pb

Refresh the extension list and install **Atlas Comics**.

This branch contains only the current extension catalog, APK, JAR, icon, and checksums. The new extension’s source and build instructions are on the [main branch](https://github.com/The-Fool-YMR/atlas-mihon-repo/tree/main).

[Download the APK directly](https://raw.githubusercontent.com/The-Fool-YMR/atlas-mihon-repo/repo/apk/atlas-comics-v1.6.1.apk).
